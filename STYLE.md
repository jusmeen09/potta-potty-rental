# Star Portable Restrooms Style Guide

This file is the source of truth for visual and typographic consistency across the homepage, About, Blog, Contact, location directory, and all generated state pages.

## Brand direction

- Call-first, practical, trustworthy, and local-service focused.
- Use strong contrast, generous spacing, obvious phone CTAs, and restrained blue/red accents.
- Avoid oversized marketing typography, cramped first folds, ornamental UI, and low-contrast text.

## Typography

Typography is role-based. The same content role must use the same family, size, weight, and line height on every page.

| Role | Font | Desktop size | Purpose |
| --- | --- | --- | --- |
| First-fold H1 | Manrope | `clamp(2.01rem, 3.24vw, 3.21rem)` | Homepage and every internal-page hero |
| Section H2 | Manrope | `clamp(2rem, 3vw, 3rem)` | Primary section headings |
| Content H3 | Manrope | `1.28rem` | Cards and subsection headings |
| Lead text | DM Sans | `1.08rem` | Hero and section-introduction copy |
| Body text | DM Sans | `1rem` | Paragraphs and general content |

- Heading line height: `1.15`.
- Body line height: `1.65`.
- Headings use Manrope; paragraphs and interface copy use DM Sans.
- Do not add page-specific H1 or primary paragraph sizes. Update the shared CSS tokens instead.
- Labels, buttons, captions, metadata, and legal text may use smaller sizes because they have different semantic roles.

### Responsive typography

- Short desktop screens use a compact shared H1 token so the CTA remains visible.
- Mobile uses the same role hierarchy at a smaller responsive scale.
- Responsive changes must be made at the token level and apply to every page type.

## Spacing

- Use the shared `.container`, `.section`, and `.section-sm` spacing primitives.
- Keep consistent space between eyebrow, heading, supporting copy, CTA, and proof points.
- First-fold content must remain readable without colliding with the header or the next section.
- Overlapping cards must feel anchored to both sections and must not obscure CTAs.

## Calls to action

- Primary conversion: phone call.
- Display: `+1 (833) 920-1299`.
- Link and schema value: `+18339201299`.
- Use red for primary call buttons and preserve clear button labels plus the visible phone number.

## Implementation rules

- Global typography tokens live in `:root` in `styles.css`.
- Location pages are generated by `scripts/generate-location-pages.mjs`; do not edit generated state HTML manually.
- Service detail pages are generated by `scripts/generate-service-pages.mjs`; update the service data or template instead of editing generated service HTML manually.
- Service pages use the same dark first-fold treatment, shared type tokens, structured content cards, visible call CTAs, and consistent section spacing as the rest of the site.
- Validate changes with `npm run validate` and `npm run build`.
- Check homepage, internal content pages, the location hub, and at least one state page at desktop and mobile widths.
