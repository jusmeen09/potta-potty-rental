# Star Portable Restrooms

A responsive four-page website base for `starportablerestrooms.com`, built with HTML, CSS, JavaScript, and Vite.

## Pages

- Home
- About
- Blog
- Contact and quote request

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Before launch

- Replace the placeholder phone number and confirm the business email.
- Connect the quote and newsletter forms to an email service, CRM, or backend endpoint.
- Replace placeholder social links and review service claims, hours, and customer testimonials.
- Add analytics, privacy terms, and production hosting configuration as needed.
