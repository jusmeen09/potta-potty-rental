# Star Portable Restrooms

A responsive, call-first local SEO website for `starportablerestrooms.com`, built with HTML, CSS, JavaScript, and Vite.

## Primary conversion

- Customer-facing phone number: `+1 (833) 920-1299`
- Telephone link: `tel:+18339201299`
- Calls are the primary conversion path; forms are not required for rental inquiries.

## Pages

- Homepage
- About
- Blog and rental guides
- Contact and call-planning page
- National location directory
- 50 state location pages at `/location/state-name/`

The location hub and state pages are generated by `scripts/generate-location-pages.mjs`. Update the generator instead of editing generated location HTML by hand.

## SEO and tracking

- Optimized titles, descriptions, canonicals, headings, internal links, and crawlable URLs
- Organization, WebSite, Service, Breadcrumb, ItemList, and FAQ structured data where relevant
- XML sitemap covering the core pages, location hub, and all state pages
- Google Search Console HTML verification tag on the homepage
- Microsoft Clarity project: `y3adfg123t`
- Direct phone CTAs throughout desktop and mobile layouts

## Local development

Install dependencies and start Vite:

```bash
npm install
npm run dev
```

The default local URL is shown by Vite, typically `http://localhost:5174/` when port 5173 is already occupied.

## Generation and validation

Regenerate the location directory and all state pages:

```bash
npm run generate:locations
```

Validate titles, descriptions, canonicals, headings, schema, FAQ parity, call paths, sitemap URLs, and homepage location links:

```bash
npm run validate:locations
```

Create the production build:

```bash
npm run build
```

`npm run build` regenerates location pages before writing deployable files to `dist/`.

## Launch checklist

- Deploy the latest production build before completing Search Console verification.
- Confirm Clarity receives sessions after deployment.
- Keep the verification and Clarity tags in the page `<head>`.
- Confirm the phone number, business email, hours, coverage statements, and testimonials before launch.
- Replace placeholder social links and publish the required privacy and legal pages.
- Test call links, navigation, responsive layouts, schema, sitemap, and Core Web Vitals after deployment.
